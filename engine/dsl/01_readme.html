Core Components

  • context_registry.py: define datos y objetos
  • resolver.py: convierte strings a valores reales
  • query_wrapper.py: limita operaciones sobre querysets
  • type_inference.py: detecta tipo automáticamente
  • operators.py: define operadores según tipo
  • evaluator.py: ejecuta comparación y devuelve True/False

Access Patterns

  • Direct ORM: lead.country, lead.progress.validated
  • Nested Relations: last_event.event_type.slug
  • Collections: event_slugs, executed_actions
  • QuerySets: events.exists(), tasks.count()
  • Rules Example: {"left": "lead.country", "operator": "equals", "right": "Argentina"}

Conceptual Model

  • resolver → trae datos reales
  • type → entiende tipo de cada dato
  • operators → define lógica aplicable
  • evaluator → ejecuta comparación y devuelve True/False
  • Resultado → sistema declarativo de automatización, reglas flexibles
