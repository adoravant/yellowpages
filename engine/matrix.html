2. Diccionario de Componentes

LeadProgress State Machine

  • validated...contract: Booleanos persistentes (Hitos).
  • milestones_context: Historial detallado (Flavor/Timestamp).
  • sync_from_event(): Inteligencia de cascada (Si es Call, entonces Validated=True).
  • current_stage: Define qué botones ve el técnico en la UI.

Event Fact

  • Registro inmutable de "algo que pasó".
  • metadata: Guarda el button_id y el technician.
  • Es el disparador para que el TriggerRule genere trabajo.

Task Execution

  • La unidad mínima de trabajo (Ej: "Mandar WA").
  • execute_at: Permite programar seguimiento futuro.
  • retry_count: Manejo de errores de API.
  • payload: Contexto dinámico para la función Python.

TriggerRule Logic

  • El cerebro de automatización (IF Event X THEN Action Y).
  • create_task_for_lead: Lógica quirúrgica para elegir el MsgTemplate según el problema de la web.
